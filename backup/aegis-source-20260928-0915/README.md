# Aegis

Mobile-first web app untuk dukungan kesehatan mental keluarga di Surabaya.

## Menjalankan proyek

```bash
npm install
npm run dev
```

## Struktur awal

- `src/components` — komponen UI reusable.
- `src/data` — mock data untuk alias, skrining, psikolog, dan booking.
- `src/pages` — halaman demo path lanjutan.
- `src/App.jsx` — Landing Page Aegis.
- `src/styles.css` — desain mobile-first dan token visual awal.

## Tahap berikutnya

Implementasi dilanjutkan dari landing page menuju skrining stres interaktif, dashboard hasil, AI assistant, konseling semi-anonim, serta admin/server view.
