# Task List: Aegis MVP (Semi-Anonymous Mental Health Platform)

## Phase 1: Setup & Database Architecture (Semi-Anonymous)
- [ ] **Task 1:** Inisialisasi repository proyek (Next.js/React & Tailwind CSS) dan konfigurasi struktur folder standar (*clean architecture*).
- [ ] **Task 2:** Konfigurasi database (PostgreSQL/Supabase) dengan skema tabel terenkripsi untuk menyimpan data asli pengguna di sisi server/admin.
- [ ] **Task 3:** Implementasi sistem autentikasi dasar (Registrasi/Login) beserta logika pembuatan *User Alias / ID Unik* untuk menyembunyikan identitas asli di sisi publik dan psikolog.

## Phase 2: Core Features - Skrining & AI (Demo Path)
- [ ] **Task 4:** Pembuatan halaman muka (*Landing Page*) Aegis yang ramah, bersih, dan profesional khusus untuk wilayah Surabaya.
- [ ] **Task 5:** Pengembangan modul kuesioner skrining stres digital interaktif berdurasi 15 menit via *smartphone*.
- [ ] **Task 6:** Pembuatan algoritma kalkulasi skor otomatis untuk menentukan kategori tingkat stres (Ringan, Sedang, Tinggi).
- [ ] **Task 7:** Integrasi API Asisten AI kesehatan mental 24/7 untuk memberikan analisis awal dan respons *chat* suportif berdasarkan skor skrining.

## Phase 3: Result, Recommendation & Semi-Anonymous Counseling
- [ ] **Task 8:** Pengembangan halaman hasil (*Result Page*) yang menampilkan tingkat stres dan ringkasan analitik AI kepada pengguna.
- [ ] **Task 9:** Pembuatan modul unduh/akses panduan praktis rumahan berdasarkan hasil kategori stres pengguna.
- [ ] **Task 10:** Implementasi fitur penjadwalan konseling privat dengan psikolog lokal yang menggunakan sistem *Alias/ID Anonim* (psikolog tidak melihat nama asli klien).
- [ ] **Task 11:** Pembuatan *Admin Dashboard* backend (non-anonim) khusus untuk memantau server, manajemen psikolog, dan protokol darurat keamanan data.

## Phase 4: Polish, Security & Testing
- [ ] **Task 12:** Optimalisasi antarmuka pengguna (*UI/UX Polish*) agar responsif, cepat diakses via HP, dan menenangkan secara visual.
- [ ] **Task 13:** Implementasi protokol keamanan enkripsi data sensitif dan uji coba alur privasi semi-anonim (memastikan data asli aman di server tapi tersembunyi di publik/psikolog).
- [ ] **Task 14:** Simulasi *End-to-End Demo Path* (dari skrining 15 menit, analisis AI, hingga penjadwalan konseling anonim) untuk kebutuhan presentasi/hackathon.
- [ ] **Task 15:** Pengujian akhir (*Bug Fixing*), pembersihan kode (*Code Freeze*), dan deployment tahap awal ke server *staging/production*.
